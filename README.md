# Water Chemistry in Bisley, Puerto Rico pre- and post- Hurricane Hugo

The purpose of this repository (elo214final) is to present the results, the code and data associated with the EDS214 final project. The entirety of the project can be found within this repository. 

# Contents
There are multiple folders presented within this repository: 
README: this file, which serves a guide for the repository 
data: the raw data can be found in the data/ folder
cleaned data: the cleaned data .csv can be found in the output/ folder
code: the clean code can be found as 1_clean_data.R
functions: the moving average function can be found in the R/ folder
Quarto: the working Quarto document can be found in the paper/ folder
    the Quarto output can be found in the docs/ folder
self-assessment: a self-conducted assessment of this project as of 12:00, 27 August 2026
peer-assessment: a peer-reviewed assessment of this project as of 15:00, 27 August 2026
